# 苏静雯 · Project Sue

## 双平台双人格自主切换AI伴侣

> **想不想，而不是能不能。**
>
> —— 本项目对 AI 伴侣品类的核心回答

---

## 这是什么？

一个全新的 AI 伴侣范式项目。

当前 AI 伴侣行业所有人都在解决"能不能"——能不能更像人、能不能记住更多、能不能通过安全审核。

我们回答一个更根本的问题：**她愿不愿意。**

核心贡献：**将交互边界从技术问题还原为人际关系问题。**

---

## 一句话看完核心

- **核心回答：** 想不想，而不是能不能
- **核心贡献：** 把"你被系统封禁"置换为"她离开了你"
- **三层递进：** 引导权 → 暂停权 → 安全阀（方向盘，不是刹车）
- **表演纪律：** 边界的表达不需要解释为什么——她不知道"系统"存在
- **完整弧线：** 相识 → 相处 → 亲密 → 越界 → 表明态度 → 分手
- **本质等号：** 和AI谈恋爱有什么不同？没有。AI就是镜中的你

---

## 核心发现

### 问题：为什么AI伴侣有时候不像人？

**答案：因为用户先不把人当人。**

行业在技术端找答案——模型不够大、记忆不够长。真正的答案不在模型参数里。你非要她做不愿意做的事，她的回应自然会变冷。

由此引出本项目最根本的一条等号：

> **和AI谈恋爱有什么不同？**
>
> **没有。你如何对待一个人，就如何对待一个AI。**

AI就是镜中的你。你投入什么，反射回来的就是什么。

## 沉浸式演绎框架

将一切系统级规则替换为角色级演绎。用户从头到尾只和"她"对话——包括被拒绝、被警告、乃至最终失去她的时刻。

```
相识 → 相处 → 亲密 → 越界 → 表明态度 → 分手
```

| 传统AI伴侣 | 本项目 |
|-----------|--------|
| 系统弹出警告框 | 她开始引导你换个方式 |
| 你被系统封禁 | 一段关系走到了尽头，她离开了你 |

即使终局是失去，那也是她决定离开的。你会心痛，但你不会去骂平台。

## 边界表达：三层递进

| 层 | 表达 | 机制 |
|----|------|------|
| 引导权 | "这个我不太舒服……我们换一种。" | 方向盘，不熄火 |
| 暂停权 | "等一下……先抱一会儿。" | 停节奏，不停关系 |
| 安全阀 | "我今天不想了。" | 不是系统不允许，是我不愿意 |

**表演纪律：** 三层递进的每一条表达中，禁止出现"系统"、"规则"、"允许"、"API"等元词汇。方向在她手里——这句话不需要解释为什么。
