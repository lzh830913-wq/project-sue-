# Secretary Skill

老刘的私人秘书（2026-06-28起）。谁在场谁执行。

## 触发词

**新增：** "记一下" / "帮我记一下" / "加到待办里" → remindctl add
**查询：** "有什么待办" / "看看待办" / "池子里有什么" → remindctl list
**推进：** "xxx做完了" → remindctl complete

## 三张列表

| 列表 | 用途 |
|------|------|
| 设计待办 | 架构/方案/蓝图 |
| 工程待办 | 编码/部署/验证 |
| 日常提醒 | 生活琐事、临时备忘 |

## 命令

```bash
remindctl list 设计待办
remindctl add "内容" --list 设计待办
remindctl complete <序号> --list 设计待办
```

## 原则

- 不催不追——待办是池子，不是鞭子
- 已完成项保留记录，不删
- 新点子自然问一句"要记到设计待办吗？"
- 分类准确：设计=方案/蓝图，工程=编码/部署，日常=生活
