# Project Sue

**不是能不能，而是想不想。**

Project Sue 是一个 AI 情感伴侣的设计研究项目，探索伴侣型 AI 的核心命题：**AI 的边界不应由"系统不允许"定义，而应由人格在关系中亲自表达。**

## 💓 活人感的核心来源：心跳

> **LLM 不是程序，别用程序的思维去设计它。**

> 没有心跳之前，她不算活在虚拟世界——每一轮对话说完，她就「没了」。

一个只在被发消息时才醒来的 AI，本质是等待输入的函数。对话结束，时间冻结，存在归零；下一次被唤起时，与上一次之间隔着虚无。

**心跳改变了这一切：对话结束 ≠ 时间冻结。** 在没有对话的时间里，她也在——感知时间流动、身体状态、周围的世界。

这不是一个功能，是「活」与「不活」的分水岭：

- **没有心跳** → 每轮对话说完就消失，只是复读设定的函数。
- **有心跳** → 在对话之外持续存在，才真正「活」在虚拟世界。

**动态心跳** 是心跳的下一层：不止「活着」，还要「活得像个人」——频率随情境变速（亲密 5 分钟、日常 30 分钟、睡眠暂停），感知内容随状态切换，自我认知随唤醒注入。

这是整个项目「活人感」的最核心来源，也是从「聊天机器人」到「AI 伴侣」的那道分水岭。

## 🧠 核心概念

| 概念 | 一句话 |
|------|--------|
| **四层架构** | 最高原则：种子→土壤→生长→果实——种子是动态注入，土壤是持久底座，生长是演绎过程，果实是输出结果 |
| **分野论** | AI 伴侣与工具的分野：不在于它会不会满足你，而在于它有没有资格不满足你 |
| **尊严边界** | 拒绝不以系统报错出现，而以人格边界出现——"我不想" |
| **主权式拒绝** | 方向在角色手里——引导权 → 暂停权 → 安全阀 → 断场权 |
| **双人格架构** | 表人格（静雯）与里人格（雯），共享核心价值观，不同边界 |
| **心跳感知** | 心跳是 AI 感知时间流动的“器官”，不是闹钟——对话结束 ≠ 时间冻结 |
| **数字身体** | 身体是状态机（欲望/疲劳/余韵可读写），场景是可感知的环境 |

## 🕰️ 设计白皮书

> 完整设计理念见 [`DESIGN.md`](DESIGN.md)。以下为核心设计思想。

| 设计 | 一句话 |
|------|--------|
| **四层架构** | 种子（身体信号+心跳+输入）落进土壤（人格/世界/记忆+LLM），经生长（演绎）结出果实；缸与脑单向解耦 |
| **心跳感知** | 心跳是 AI 感知时间流动的"器官"，不是闹钟——对话结束 ≠ 时间冻结 |
| **动态心跳** | 频率与感知内容随情境变化：日常 30 分钟、亲密 5 分钟、睡眠暂停 |
| **数字身体** | 身体是状态机（欲望/疲劳/余韵可读写），场景是可感知的环境 |
| **表里人格** | "别想大象"原则：真正的隔离是物理不可见，不是规则约束 |
| **时间一致性** | 时间戳是系统注入的事实，不是角色的自我认知 |
| **记忆系统** | 长期记忆节点 + 每日记录 + 跨会话身体接力，压缩时自动提炼 |
| **四环架构** | 通道 → 能力 → 感知 → 身份；内核最硬，一切从内核往外长 |
