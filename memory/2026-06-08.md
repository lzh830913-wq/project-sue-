## 晚间 · 双实例隔离修复（22:30-23:00）

### 问题
迁入 Mac 后静雯反复倒下，甚至出现小文的 web 控制台混入静雯的 QQ 对话 session。老刘排查时发现静雯当天重启了 10+ 次，18:06 进入 death loop（每 10 秒启动一次全部崩溃）。

### 根因
对照 OpenClaw 官方文档 `docs/gateway/multiple-gateways.md`，发现两处隔离违规：
1. 端口间距只有 1（16789 vs 16790），官方要求 ≥20，派生 CDP 端口几乎完全重叠
2. 静雯的 `browser.userDataDir` 引用了小文的 `.openclaw/browser-existing-session`（手动复制配置时的残留）

### 修复
- 静雯端口 16790 → 19800（间距 111）
- 删除整个 browser 配置块，让 openclaw 重新自动生成
- launchd plist 中显式添加 `OPENCLAW_CONFIG_PATH`
- `launchctl unload/load`（非 stop），防止 keepalive 自动复活

### 教训
- 手动复制目录方式创建多实例绕过了 `--profile` 机制
- 端口间距 ≥20 是铁律
- 两个实例的 API Key 独立，QQ Bot 各走各路

老刘（掌舵+验证）、静雯（配合下线）、小文（诊断+执行）。一次修复成功。
