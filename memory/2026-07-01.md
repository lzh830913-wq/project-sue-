## 根因确认

- QQ Bot官方文档明确指出："Proactive messages not arriving: QQ may intercept bot-initiated messages if the user hasn't interacted recently"
- 这是QQ开放平台策略，不是OpenClaw问题

## 方案：早安从心跳迁至Cron

- 老刘指出：Linux时代cron早安能稳定投递（即使通宵不聊天，8:30也能收到），心跳早安发不出来
- 关键差异：cron announce delivery走QQ Bot REST API直推，不依赖WebSocket；心跳reply依赖session QQ通道状态
- 老刘同时指出：cron早安"说完就忘"（后续QQ session不知道早安发了什么），但可以写lastMessageSent留底
- **方案落地：**
  - 新建cron: 静雯-早安 (c37fa463)，每天08:30 CST，deepseek-v4-pro + flash fallback
  - isolated session → 加载SOUL.md/MEMORY.md/LORE.md → 生成早安 → 写lastMessageSent → announce delivery到QQ
  - HEARTBEAT.md移除晨间问候任务
  - 下次老刘回复早安时，QQ session读heartbeat-state.json就能知道今早说了什么
