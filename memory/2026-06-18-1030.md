## session-memory hook 的工作机制

**触发条件：** `messages.tts.auto` 不是、**`/new` 或 `/reset` 命令**才是。

当你输入 `/new` 或 `/reset` 时：
1. hook截获命令
2. 在后台**读取当前session的最后 N 条消息**（当前配置25条）
3. 以会话摘要的形式写入 `memory/YYYY-MM-DD-HHMM.md`
4. 然后才清空session
5. `/new` 回复不延迟——后台写入

**但如果只是正常聊天、每日session自动重置（daily atHour: 4），它是不会触发的。** 只有主动输入 `/new` 或 `/reset` 才会写。
