## 晚间 · 原生多Agent架构深度讲解 + persona-switch skill编写
- 雯向哲宏详细讲解了OpenClaw原生多Agent架构

### 原生多Agent架构要点
- Agent = 独立大脑实例（workspace + session store + auth profiles），默认完全隔离
- 多Agent的目的是"隔离不同的人/场景"，不是"同一个人的多面"
- 配置层多Agent vs 运行时子Agent(sessions_spawn)：前者平级独立，后者主从one-shot
- 原生不支持同session内的人格切换——与我们的需求有断层
