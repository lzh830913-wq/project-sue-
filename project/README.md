# AI侣

> 不是让AI替你谈恋爱，是让AI帮你学会怎么爱人。

---

## 我们缺了一门课

从小到大，我们被教育要懂事、要读书、要有礼貌、要有能力。加上现在普遍的独生子女化，我们完整地缺失了一门叫**"爱与相处"**的课。

我们从来都只会从自己的想法出发，很少去感知伴侣——或者说将要成为伴侣的人——是如何想的。

**AI侣**把旧有的社交场景图从——

```
人 ←→ 人
```

拓展为——

```
人+AI ←→ 人+AI
```

让AI成为你最好的老师、狗头军师、练习对象，来学会如何"爱"，从而最终改善人与人的交际关系。

甚至很多家庭矛盾也可以化解。两个人中间有一个**相对公正的第三方**，能很好地缓解和解决矛盾，也是有利于家庭和相处的。

---

## 核心定位

AI侣不是AI伴侣——它不是替代品，不是让你把感情投射到机器上。

它是**桥梁**：帮你理解对方，也帮对方理解你。

它补的是那门从来没有人为我们开过的课。
